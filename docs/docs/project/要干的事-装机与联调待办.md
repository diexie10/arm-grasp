> **S1 精确性有待实测估计**，本清单只列"要怎么估"，不给结论。

- [ ] S1-1 **零点**：什么舵机角 = 俯视 0°（朝右）→ 定 `JOINT_OFFSET[0]`

- [ ] S1-4 **真行程**：底座机械可转范围（≠ 舵机 0–270°）
