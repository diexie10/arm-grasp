# 拼装与测试指导（Bring-up Plan）

> 目的：硬件到货后按阶段拼装，**每拼到一个里程碑就停下来测试**，通过才进下一阶段。
> 原则：先电源 → 再最小系统 → 再单舵机 → 再全臂 → 再传感器 → 再视觉 → 最后全流程。
> 每阶段有明确"通过标准"，不达标不往下走。所有测试结果回填 `docs/project/诚实声明与技术债务清单.md`（划掉推测值）。

---

## 阶段 0：物料清点与工具准备

**拼装内容**：无。清点 BOM。

**检查清单**：
- [ ] 6×MG996R 舵机（含舵盘/螺丝）
- [ ] STM32F103C8T6 板（Blue Pill）
- [ ] 6V 8A 电源 + DC 母头线
- [ ] X16GF800 PTC 8A（串 6V 正极）
- [ ] 电容：25V 10000μF×1 + 470μF×4 + 100nF×10
- [ ] 100Ω 电阻×6（信号线串联）
- [ ] 红外对管 QT30CM×2
- [ ] USB 摄像头 / DroidCam 手机
- [ ] 杜邦线、端子排、18AWG 电源线
- [ ] 夹爪硅胶/TPU 指垫材料（刚性爪体 + 柔性指垫，抓握摩擦）
- [ ] 夹爪开口 ≥45mm + 爪口倒角（方块 35mm，单边 5mm+ 容差；调研 2026-08-18）

**工具**：万用表（必备）、ST-Link、USB 线、量角器+直尺（标定用）、示波器（可选）。

**测试方法**：
1. 万用表测 6V 电源**空载电压**：应为 6.0V ± 5%（5.7~6.3V）。
2. 万用表测 PTC 冷态电阻：应接近 0Ω（导通）。

**通过标准**：电源空载电压正常、PTC 导通、物料齐全。

## 阶段 0.5：官方资料速查（拼装前必读）

> 详情见 `hardware/官方资料要点.md`（官方安装手册 + .ino + 3D 模型提炼）。

**螺丝规格规则**（严禁乱用，装错是新手最常见错误）：
- M3*6 → 舵盘
- M3*8 → 顶部两个舵机（爪子舵机+异形舵机）、支架与支架接合、法兰轴承
- M4*8 → 底部四个舵机与支架接合

**舵机归中（最关键一步，装错只能拆了重装）**：
1. 确认归中位置：1500µs = 90° 中点（0°=500µs、180°=2500µs）
2. 判断舵机类型：装舵角后手转，转不动 = 带限位；能一直转 = 数字舵机不带限位
3. 带限位：逆时针转不动 = 0°，顺时针转不动 = 180°（找到 90° 中点即可）
4. 不带限位：必须通电测 1500µs 找中点
5. **所有舵机先归中（90°）再安装**，然后按官方方向图装配（S1 底座 0-180°、S2 90° 朝上、S3/S4 补角映射 `舵机角=180−关节角`——⚠️ 安装方向与我们 config 的 JOINT_OFFSET 假设可能不同，阶段 6 实测确认）

**10 步拼装顺序**：U型横梁 → 多功能支架+底部 → 凸抬+L 型支架（左右镜像）→ 多功能支架 → 长 U 形支架 → 异 U 形支架装舵机（螺丝由下往上）→ 拼合 → 左边三舵机 M4*8 → 手爪舵机 → 装手臂。

## 阶段 1：电源系统（不接舵机）

**拼装内容**：`6V电源 → DC母头线 → PTC → 端子排红排`（黑线接端子排黑排，**舵机先不接**）。

**测试方法**：
1. 上电前万用表**通断档**测红排与黑排之间：应不导通（无短路）。
2. 上电后测红排-黑排电压：6V ± 5%。
3. 手摸 PTC：常温，不发热。
4. 断电，测红排对地（USB GND 未接时先不测共地）。

**通过标准**：电压 6V±5%，无短路，PTC 不发热。

> ⚠️ 此时**不要**接舵机、**不要**接 STM32。电源系统是炸机高发区，单独验证。

## 阶段 2：MCU 最小系统 + 烧录

**拼装内容**：STM32 板 + ST-Link（SWD: PA13/PA14，BOOT0=0）+ USB 线连电脑。

**测试方法**：
1. ST-Link 连接，`keil-mcp_flash_target` 烧录固件（或 UV4 -flash）。
2. 烧录后拔 ST-Link，插 USB 线。
3. 设备管理器 → 端口：应出现 **STMicroelectronics Virtual COM Port**（VID 0483 / PID 5740）。
4. 若枚举失败：检查 PA11/PA12 无外接、USB 时钟 48MHz、堆 1KB（startup 0x400）。

**通过标准**：设备管理器出现 COM 口，无感叹号。

## 阶段 3：USB CDC 通信（无舵机）

**拼装内容**：无新增。用串口助手（或 `pc/arm_serial.py`）连 COM 口。

**测试方法**：
1. 发 `S\r\n` → 应回 `S1=90 S2=90 S3=90 S4=90 S5=90 S6=90`。
2. 发 `I\r\n` → 应回 `IR1=1 IR2=1`（红外未接/未遮挡时上拉=1）。
3. 发 `M1 90\r\n` → 应回 `OK M1 90`（舵机未接，仅验证协议）。
4. 发 `M1 200\r\n` → 应回 `OK M1 180`（**限位钳位验证**，回显 clamp 后值）。
5. 发 `XYZ\r\n` → 应回 `ERR`。
6. 发 `M1 -5\r\n` → 应回 `ERR`（负角度拒绝）。

**通过标准**：以上 6 项全部符合。**回显铁律在此阶段验证**——回显必须是 clamp 后实际值。

## 阶段 4：单舵机 + PWM（只拼底座）

**拼装内容**：只接 **1 个舵机**到 J1 通道（PA8 = TIM1_CH1），信号线串联 100Ω，电源接端子排红排。**机械臂骨架先不拼**，舵机放桌面。

**测试方法**：
1. 上电，发 `M1 90\r\n` → 舵机应转至中位（舵盘与外壳平行）。
2. **脉宽范围实测（必测，先于角度测试）**：
   - 发 `M1 0\r\n`（固件发 0.5ms）→ 观察舵机：正常停在 0° 附近 = 0.5ms 可用；**异响/硬顶/超行程 = 舵机实际下限是 1ms**
   - 发 `M1 180\r\n`（固件发 2.5ms）→ 同理判断上限
   - **若 0.5ms 或 2.5ms 异常** → 改固件 `SERVO_MIN_PULSE/MAX_PULSE` 为 1000/2000（1-2ms），重新编译烧录，重测
   - 依据：商家时序图标明 1ms≤脉宽≤2ms（0°=1ms/90°=1.5ms/180°=2ms），与固件 0.5-2.5ms 可能不匹配；MG996R 官方规格是 0.5-2.5ms，实际以实测为准
3. 发 `M1 45\r\n` → 用**量角器**实测舵盘角度：45°±5°。
4. 观察抖动：舵机保持角度时不应持续抖动（轻微嗡嗡声正常，剧烈抖动=电源问题）。
5. 手摸舵机：运行 2 分钟后微温（<50°C）。

**通过标准**：脉宽两端实测正常（或已改固件适配）、角度对应正确（量角器 ±5°）、无剧烈抖动、不过热。

> ⚠️ 这一步是**全项目最关键的单点验证**：PWM 极性、脉宽映射、电源能力、信号线 100Ω 是否有效。单舵机都抖，6 个舵机必炸。

## 阶段 5：全舵机 + 软启动 + 限位（拼完整骨架）

**拼装内容**：拼完整机械臂骨架（底座→大臂→小臂→腕→夹爪），6 舵机全部接上。**先手动把每个舵机转到 90° 中位再装舵盘**，避免装盘后角度错乱。

**测试方法**：
1. **软启动**：用 `pc/main.py`（或手动逐个发）`M1 90` → 等 200ms → `M2 90` → ... → `M6 90`。**严禁 6 路同时上电**（15A 瞬态）。
2. 发 `S\r\n` → 6 个角度全 90。
3. 逐关节限位测试：`M2 0` → 回显 `OK M2 30`（J2 下限 30）；`M3 180` → 回显 `OK M3 150`（J3 上限 150）；`M5 0` → 回显 `OK M5 45`；`M6 180` → 回显 `OK M6 120`。
4. 观察：6 舵机同时保持角度时无抖动、电源线不发热、PTC 不动作。
5. 手摸 6 个舵机：运行 5 分钟后均 <50°C。

**通过标准**：软启动无异常、限位钳位全部正确、无抖动、无过热、PTC 不误动作。

> ⚠️ 若 PTC 在软启动时动作（断电）：说明瞬态仍超 8A，需检查是否 6 路同时上电、或电源线过细。

## 阶段 6：机械参数实测（IK 正确性的根基，最重要）

**拼装内容**：无新增。机械臂已完整拼好。

**测试方法**（逐项实测，回填 config.py + 固件限位表）：

1. **JOINT_OFFSET 实测**（每关节）：
   - 发 `M<n> 90`，用**量角器**测该关节机械角度。
   - J2：舵机 90° 时大臂应水平（0° 关节角）→ 验证 offset 90 假设。
   - J3：舵机 90° 时小臂相对大臂 90° → 验证 offset 0 假设。
   - J4/J5：同理验证 offset 90。
   - **若实测不符 → 改 `pc/config.py` 的 JOINT_OFFSET**。
2. **连杆长度实测**（⚠️ 当前 config 工作值：L1=72 / L2=105 / L3=128（官方参数待实测复核，以实测为准）；另 config 注释有 L4=170（J4→爪尖）**未入 IK 模型**——见第 5 项语义核对）：
   - 直尺量：J1 轴心到 J2 轴心（L1）、J2 到 J3（L2）、J3 到 J4（L3）、J4 到爪尖（L4）。
   - **若实测不符 → 只改 `pc/config.py` 的 L1/L2/L3/L4**。机械长度日后任何调整（换件/改装）同样**只回填 config**，逻辑代码禁止硬编码长度/角度（用户裁决 2026-09-06：臂长可能因其他情况调整）。
3. **关节限位实测**：
   - 逐关节发 `M<n> 0` 和 `M<n> 180`，观察**机械挡块**实际停在哪。
   - 记录实测 min/max → 改固件 `joint_min/joint_max` 表 + `pc/config.py` JOINT_LIMITS。
4. **过冲量实测**（消隙）：
   - 发 `M1 90` → 等稳定 → 发 `M1 95` → 再发 `M1 90`，用标记物观察回程是否到位。
   - 若回程有虚位（差 >3°），增大 OVERSHOOT_DEG（当前 15°）。
5. **IK 目标语义核对（第 0 优先——决定低 z 问题的真伪）**：
   - 发已知关节角 G，实测**爪尖**位置，与 `kinematics.fk` 预测的 J4 点对比。
   - 判读：爪尖 ≈ J4 点竖直下方 ~L4 → IK 目标是"腕点"，桌面级低 z 抓取可能**无需肘下分支**（腕点悬 ~L4+块高即可，j3 保持正角度）——第三轮"低 z 不可达"结论需重审；爪尖 ≈ J4 点 → L4=170 注释失实需更正。
   - 回填：kinematics.py（注释锁定语义或工具偏置入模）+ 诚实声明对应行。
6. **S3 负角度行程实测**：断电状态手转 S3 越过 JOINT_MIN[2]（比带电试探安全），确认是否存在负角度行程 → 决定肘下分支激活（放宽限位）或保持休眠。
7. **虚位（backlash）量化**：各轴小幅换向（如 M1 90→95→90），标记物/相机测末端位移阶跃 → 回填 config 对齐死区 `ALIGN_DEADBAND_MM`（预期对应 0.5~1.5°/轴）。
8. **每 bite 稳定时间**：手机慢动作拍 S1 大摆（≥90°）全程，逐 bite 量"抖动消失耗时" → 回填固件 `STEP_DWELL_TICKS`（当前 33 tick=0.66s，经验定时非实测）。
9. **大摆时间账**：发 90° S1 单 G 秒表计时，对照 PC 超时预估（bite 感知公式）→ 回填 `DONE_TIMEOUT_FACTOR/EXTRA`；偏差 >10% 则同步校 config 的 bite 镜像常量。

**通过标准**：JOINT_OFFSET/L1/L2/L3/L4/限位全部实测值回填 + IK 目标语义结论明确 + S3 负行程结论明确，`python main.py --dry-run --mode test` 仍通过。

> ⚠️ **此阶段不达标，禁止进入视觉/抓取阶段**。IK 参数错，抓取位置全偏，后面全白做。

## 阶段 7：红外对管

**拼装内容**：IR1→PB12、IR2→PB13（输入上拉），红外发射/接收对装到夹爪两侧（对射式，间距 <3cm）。

**测试方法**：
1. 发 `I\r\n` → 未遮挡应回 `IR1=1 IR2=1`。
2. 手指/木块遮挡 IR1 → 回 `IR1=0`；遮挡 IR2 → 回 `IR2=0`。
3. **极性验证**：若遮挡后回 1（反了）→ 固件取反一行（`HAL_GPIO_ReadPin` 结果取反）。
4. **输出类型验证**：若未遮挡时回 0（悬空）→ 模块是开漏输出，需加 4.7kΩ 上拉到 3.3V。
5. 用 3.5cm 木块实测遮挡：应 100% 触发（对 940nm 红外全遮挡）。

**通过标准**：遮挡=0、未遮挡=1，木块触发可靠。

## 阶段 8：视觉 + 标定

**拼装内容**：摄像头固定（eye-to-hand 俯视，正对抓取区域），USB 连接电脑（或 DroidCam）。

**测试方法**：
1. `pc/vision.py` 单测：放木块在抓取区，运行检测 → 输出 bbox 与 conf（应 >0.6）。
2. **四点标定**：`pc/calibration.py`，用 4 个已知位置点（如 A4 纸四角）标定 H 矩阵。
3. 验证：放木块在 4 个验证点，检测坐标 → 换算世界坐标，与实测对比，**误差 <5mm**。
4. 若边缘误差大（>2px）：启用 undistort（UNIMPLEMENTED P1 项）。
5. **J4-slack 视觉容忍度**：J4 偏离竖直 ±5/10/15°，观察 OBB 检测置信度与框稳定性 → 回填 `J4_SLACK_DEG`（预置 ±10°，"视觉没那么矫情"待实证）。
6. **J5 横向位移杠杆**：J5 转 ±10° 量爪尖横向位移 → 回填 `WRIST_LATERAL_MM_PER_DEG`（≈0 则 J5 仅做姿态/朝向对齐，横向微调仍归粗层）。
7. **CAMERA_OFFSET_X/Y 标定**：夹爪对准木块时记录像素坐标 → 回填 config（伺服对齐偏移补偿用，默认 0=旧行为）。

**通过标准**：标定误差 <5mm，YOLO 稳定检出木块，J4-slack 容忍度结论明确。

## 阶段 9：全流程联调（真机首次抓取）

**拼装内容**：无新增。全部子系统已就绪。

**测试方法**（按顺序，每步通过才下一步）：
1. **DRY_RUN 复跑**：`python main.py --dry-run --mode test` → grasp result: True（确认上位机逻辑未因参数回填破坏）。
2. **真机单次抓取**：`python main.py --mode test`（**去掉 --dry-run**，确认护栏提示后继续）。
   - 木块放抓取区中心，观察：检测 → 臂到目标上方 → 逐层下降 → 红外触发 → 夹爪闭合 → 抬升 → 放置。
   - 失败点记录：检测失败 / IK 不可达 / 红外未触发 / 夹爪没抓住 / 轨迹撞物。
3. **连续抓取**：`python main.py --mode loop`，10 次。
4. **异常测试**：
   - 抓取中途拔 USB → 臂应在 10s 内 limp（PWM 停）。
   - 抓取中途关上位机 → 同上。
   - 发 `E` 急停 → 立即 limp；发 `H` → 恢复。
   - 木块放不可达位置 → 状态机应转 ERROR → 安全回退，**不盲抓**。
5. **S2 咬合满负载观察**：夹最大木块下 S2 大角度移动，看抖动/迟滞（axis_steps[1] 已开 bite 模式）→ 异常则回退为连续模式并记录。
6. **对齐环分层行为观察**：末端对齐确认腕层（J4）微调先动、粗层（S1/S2/S3）只在腕层饱和/停滞后被唤醒；若末端仍持续抖动（极限环）→ 回查 `ALIGN_DEADBAND_MM`/`COARSE_MIN_STEP_DEG`/`WRIST_QUANTUM_DEG`。
7. **EMA/面积比调参**：伺服增强既有项（EMA_ALPHA、DESCEND_AREA_TARGET、SERVO_SWITCH_AREA_RATIO）按实机收敛表现调整。

**通过标准**：单次抓取成功；10 次连续抓取成功率 ≥70%；异常测试全部符合预期。

## 快速排障表

| 现象 | 排查顺序 |
|------|---------|
| 舵机抖动 | ①电源不足（最常见）→ ②共地是否接 → ③PWM 频率 → ④信号干扰（100Ω/线距） |
| USB 枚举失败 | ①PA11/12 无外接 → ②堆 1KB → ③48MHz 时钟 → ④ST-Link 重烧 |
| 舵机不动 | ①信号线接对（PA8-1号）→ ②电源共地 → ③PTC 是否动作 → ④限位钳位（回显看） |
| 红外不触发 | ①极性反（取反）→ ②开漏需上拉 → ③对射间距过大 → ④木块不遮 940nm |
| IK 位置偏 | ①JOINT_OFFSET 未实测 → ②L1/L2/L3 未实测 → ③标定误差大 → ④回显铁律被破坏 |
| 抓不住 | ①夹爪行程不够 → ②GRIP_WAIT 太短 → ③木块位置偏 → ④J6 限位钳位 → ⑤夹爪开口/指垫容差不足（目标开口 ≥45mm + 倒角 + 硅胶指垫） |

## 关键纪律
