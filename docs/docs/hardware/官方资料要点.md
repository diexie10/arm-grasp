## 2. 舵机安装方向图（.ino 头部 ASCII 图）⚠️ 拼装后实测确认

```
        S3  0°        S4  0°     S5        
      90° |---------------|-------|---  90°
          | 180°          180°       S6        
          |
          |
          |
          | 90°
   180°   | S2     0°
   -----------------
          S1
```

- S1 底座 0-180°、S2 90° 朝上、S3/S4 的 0°/180° 方向、S5/S6 手爪
- 官方默认舵机角映射：`servo2.write(Theta_2)`、`servo3.write(180 - Theta_3)`、`servo4.write(180 - Theta_4)`
- **S3/S4 舵机角 = 180 − 关节角**（补角，因安装方向；若方向相反则不用补角）
- ⚠️ 我们 config.py 的 JOINT_OFFSET 假设（J2 offset 90、J3 offset 0）与官方默认方向**可能不同**，拼装后必须逐关节实测"舵机 90° 时机械位置"（诚实声明清单已有此待办）

## 3. PWM 映射（.ino + 手册双重确认）

- **0° = 500µs、90° = 1500µs、180° = 2500µs**
- 官方代码显式设置 `min_PWM=500, max_PWM=2500`（Arduino Servo 库默认 544-2400，官方特意改宽）
- 手册原文"0度对应500ms位置，180度对应2500ms位置"（ms 为 µs 笔误）
- ⚠️ 需核对固件角度→PWM 映射是否一致（500-2500µs）

## 4. 官方 IK 坐标系命名（.ino）

- 官方：X_EE=左右、Z_EE=前后、**Y_EE=高度**（`Zoffset = Y_EE - L1`）
- 我们：x=前后、y=左右、z=高度——命名不同但结构一致
- **官方代码有 bug**：`X_EE==0` 分支 `D = sqrt(X_EE² + Y_EE²)` 用了 Y_EE（应为 Z_EE）——官方代码不可直接照搬，我们用自己的 kinematics.py 是对的

## 5. 舵机逐个运动 + 200ms 延时（.ino loop）

- 官方逐个写角度、每个 delay(200)——与我们的软启动设计（逐个 200ms）一致，验证设计

## 6. 螺丝规格规则（手册）——拼装直接用

| 规格 | 用途 |
|------|------|
| M3*6 | 舵盘 |
| M3*8 | 顶部两个舵机（爪子舵机+异形舵机）、支架与支架接合、法兰轴承 |
| M4*8 | 底部四个舵机与支架接合 |

- 手册强调"严禁乱用规格"——装错规格是新手最常见错误

## 7. 舵机归中方法（手册）——拼装关键步骤

- 1500µs = 90° 中点（不需要特别精确）
- **带限位舵机判断法**：装舵角后手转，转过一定角度转不动 = 内部带限位；能一直转 = 数字舵机不带限位
- 带限位舵机：逆时针转不动 = 0°，顺时针转不动 = 180°
- 不带限位舵机：必须通电测试找 1500µs 中点（写代码或用舵机控制器）
- **安装前先归中再安装**（"舵机每个都调整好角度后再安装，设置角度为90度"）

## 8. 10 步拼装流程（手册）

1. 拼合两个 U 型横梁（M3*8×8 + M3 螺母×8）
2. 固定多功能支架与底部 U 型横梁（先固定支架再固定舵机，舵机用 M4*8，方向与图相反）
3. 拼合凸抬与 L 型支架（M3*6×8，左右镜像对称安装）
4. 拼合多功能支架（M3*8×8 + M3 螺母×8，左右镜像）
5. 拼合两个长 U 形支架并与步骤 4 拼合
6. 异 U 形支架上固定舵机并安装舵盘（M3*8，舵机固定螺丝由下往上）
7. 将装好舵机的异 U 形支架与步骤 5 拼合
8. 左边三个舵机用 M4*8（M3*6×10 + M4*8×12 + M4 螺母×12）
9. 安装舵机到机械手爪并固定到主体（M3*6×9 + M3 螺母×4）
10. 安装手臂到步骤 2 的多功能支架（M3*6×5 + M3*8×5 + M3 螺母×4）

**左右镜像对称安装**是反复强调的点。
