# 6-工程规范与最佳实践（调研落地）

> 状态：**2026-09-10 定稿**。来源：对成熟开源项目的调研（GRBL / Klipper / Marlin / RepRapFirmware / Modbus / micro-ROS / ros2_control / MoveIt Servo / ikpy / Cosmic Python / PEP 544 / Fowler 等，见 §附录）。
> 目的：把"该怎么写"钉死，**防止再次出现"手工同步常量 → J2/J4 差 90°"这类跨边界 bug**。
> 性质：**规范（应然）**；现状差距与整改见 §7。关联：`5-柱坐标运动学与双视图模型.md`。

## 0. 总原则

1. **单一真源（Single Source of Truth）**：任何同时出现在两端的量，必须有唯一权威来源。
2. **层内自洽 ≠ 跨边界正确**：模块内部一致，不代表与固件/硬件一致；**边界必须被自动校验**。
3. **功能核心 / 命令外壳（Functional Core, Imperative Shell）**：纯逻辑在内，I/O 在外，构造器注入。
4. **不测不声称**：没跑过的结论不写。

## 1. 协议层规范

| 规则 | 依据 |
|---|---|
| 帧 = ASCII 行 + `\n`（自同步、可人读、MCU 易解析） | GRBL / Marlin / SimpleFOC / RepRapFirmware |
| 校验 ≥ XOR（`*XX`）；EMI 严重时上 **CRC-16**（CCITT / Modbus 0xA001） | Marlin XOR；Klipper / Modbus CRC-16 |
| 流控 = 请求-应答 `OK/ERR`，发一条等一条 | GRBL |
| 实时查询 = **单字符**即时命令，绕过行缓冲 | GRBL `?` |
| 超时 + 清缓冲再同步（换行自同步） | pyserial / GRBL |
| 错误用 `ERR <code>` 枚举，禁裸字符串 | GRBL / Marlin |

**本项目现状**：已是 ASCII 行 + XOR + `OK/ERR` + 超时清缓冲 → **合规**。可选增强：单字符实时状态、错误码枚举。

## 2. 单一真源规范（**直击 P0，最高优先**）

- **禁止**跨端手工镜像常量（本项目 P0 正是它）。
- 必选其一，**强烈建议两者都上**（纵深防御）：
  - **(a) 运行期握手**：主机连接时向 MCU 查询实际限位/范围并缓存。
    依据：GRBL `$$` 设置表；Klipper 数据字典 + `DECL_CONSTANT`；RepRapFirmware Object Model。
  - **(b) 单一真源代码生成**：一份 YAML/pydantic → 生成 C 头 + Python 常量，两端同源。
    依据：nanopb/protobuf、OpenCyphal/nunavut、Jinja2 代码生成（见附录）。
- **(c) 跨边界一致性测试（兜底，已落地）**：测试解析固件源码常量，断言与主机 config 一致。
  已加：`pc/tests/test_firmware_contract.py`。

**本项目现状**：手工镜像 → **违规**。已加 (c)；建议再上 (a) 握手（约 20 行 C + 15 行 Python）。

## 3. 模块解耦规范

- **端口-适配器（Hexagonal）**：domain 纯函数；serial / camera / time / fs / network 全在 shell。依据：Cosmic Python。
- 接口用 **`typing.Protocol`**（结构化鸭子类型），非继承；`abc.ABC` 仅当自有层级需实例化时强制。依据：PEP 544 / Real Python。
- **依赖注入**：构造器注入，禁 DI 框架。
- **时钟注入**：`Clock` 协议（`now/monotonic/sleep`）；热点路径**禁裸 `time.sleep`**；测试传假钟。依据：python-testing-debugging。
- **状态机**：≥6 状态用 `python-statemachine`（声明式、定义期校验、可出图）或 `transitions`；<5 状态可手写。依据：pytransitions / python-statemachine。
- **层次方向**：I/O 层**不得**被纯逻辑层 import（依赖只能由外向内）。

**本项目现状**：数学/IO 已分离（`servo_controller`/`kinematics`/`imu_filter` 纯）✓；但**全局 `config` 单例**、**god-class**、**时间直调** → 违规（见 §7）。

---

## 4. 坐标 / 运动学规范

- 位置空间用**柱坐标 `(r, φ, z)`**；基准旋转轴 = J1；绕轴奇异 `r→0` 设下限。依据：圆柱坐标机器人文献；见 `5-柱坐标运动学与双视图模型.md`。
- **关节↔舵机映射：舵机域为真源，关节域由 offset 派生**（本轮已修）。
- IK：解析解（base yaw 解耦 + 平面 2 连杆）；**不上** KDL/TRAC-IK（过重，收益低）。

## 5. 安全规范

| 规则 | 依据 |
|---|---|
| 命令看门狗（N ms 无命令 → 停） | MoveIt Servo `incoming_command_timeout`；GRBL |
| 软限位（发送前校验/clamp） | GRBL soft limits |
| 近限位**速度线性缩放**（非硬停） | MoveIt Servo `jointLimitVelocityScalingFactor`（本项目已借鉴） |
| 硬 e-stop **独立于软件** | GRBL（e-stop 直连复位） |
| 位置未知则拒动 / 开机强制归零 | GRBL homing init lock |
| 开环舵机回零：**两级**（快搜索→慢定位→回退） | GRBL homing |
| 虚位：单向逼近 / 方向感知补偿 | GRBL homing / RoArm / ServoProject |
| 可选绝对反馈：**AS5600** 磁编码器（I²C） | Infineon datasheet / team-deimos |

## 6. 测试规范

- **测试金字塔**：单元 ~75% / 集成 ~20% / E2E ~5%。
- **测试替身：Fake > Stub > Mock**（Fake 跑真逻辑）。依据：Fowler《Mocks Aren't Stubs》。
- 纯层（`kinematics`/`servo_controller`/`imu_filter`/`mapping`）**必须可无硬件运行**。
- **跨边界契约测试必做**（§2c）。
- 快照/黄金测试：协议字节级回归。
- 属性测试（Hypothesis）用于解析/状态不变量（可选）。
- 覆盖率是地板不是天花板；可选用 mutmut 验证"测试真能抓 bug"。

**本项目现状**：仅 1 个真测试（glove Mahony parity），无框架 → **违规**。
