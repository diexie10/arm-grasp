## 1. 结论：位置空间是**柱坐标**，不是笛卡尔

机械臂腕点位置 = **柱坐标** `(r, φ, z)`：

| 分量 | 含义 | 表达式 |
|---|---|---|
| `φ` | 方位角 | `= J1` —— **唯一的角度自由度，全压在 S1 上** |
| `r` | 水平半径 | `r = L2·cos(j2) + L3·cos(j2+j3)` |
| `z` | 高度 | `z = L1 + L2·sin(j2) + L3·sin(j2+j3)` |

**原因**：J2 回转轴与 J1 轴**共线**（仅相差竖直高度 `L1`）⇒ 工作空间是**绕 J1 轴的旋转体**（不是一般球坐标）。
若把原点搬到肩部(J2)，对腕点即为**球坐标**（距离 ρ、方位 φ、仰角 `a2`）——两种说法等价，只是原点不同。

**代码对应**（右手系，Z 向上，原点 = J1 轴心 / 桌面）：
- FK：`kinematics.py:129-138`
- IK：`kinematics.py:50-74`（`r = hypot(x,y)`；`j1 = atan2(y,x)`；随后平面 2 连杆）

## 2. 双视图模型

| 视图 | 坐标系 | 画法 | 拖拽语义 |
|---|---|---|---|
| **俯视图** | **极坐标**（圆心 = J1 轴） | 角 = S1 的半径线、长度 = r；底座画同心圆(r) + 辐条(S1) | 角向拖 → **S1**；径向拖 → **r** → 反解 S2/S3 |
| **侧视图** | **r–z 笛卡尔**（J1 所在的竖直平面） | 水平轴 = r，竖直轴 = z；2 连杆 + 关节 | 拖 → `(r,z)` → 反解 S2/S3 |

**联动**：两视图共享同一个 `r` —— S2/S3 动则两视图**同步**变化；S1 动**只旋转俯视图**。这是物理上诚实的耦合，比用 x/y 直角坐标硬凑干净得多。

## 3. 奇异与边界（由模型直接推出）

1. **轴奇异 `r→0`**：臂竖直居中时 S1 欠定/病态，笛卡尔的微小误差会放大成巨大 S1 变化，俯视图方向乱跳 ⇒ 控制与 UI 必须设 **r 下限**或回避中心区。
2. **共轴是假设**：若 J2 轴相对 J1 轴有**前向偏置**，则 `r` 带常数偏置、俯视图不是"从圆心的纯半径" ⇒ 装配实测确认。
3. **末端 ≠ 腕点**：爪尖相对腕点还有 `L4` + 姿态(J4/J5) 偏置。俯视图"臂线"应画到**腕点**，夹爪**单独画朝向**；**L4 不得塞进极坐标半径**（否则重蹈"IK 语义：腕点 vs 爪尖"的坑）。
4. **显示约定 ≠ 内部约定**：UI 中 **S2 零位 = 竖直向上**，而 IK 中 `j2=0` = **水平**（差 90°）。需 `LINK_ZERO_DEG / DIAL_SIGN` 逐关节标定（`config.py:58-66`）。

## 4. S1 零点 / 方向 / 线性度（极坐标下最敏感）

极坐标里 S1 是**唯一**的角度自由度 ⇒ **S1 的零点与方向直接决定俯视图正确性**；且不像 S2/S3 有重力做隐式校验。

| 项 | 含义 | 回填 |
|---|---|---|
| **零点** | 什么舵机角 = 俯视 0°（朝右） | `JOINT_OFFSET[0]` |
| **方向** | 舵机 +1° 时俯视顺时针/逆时针 | `DIAL_SIGN[0]` |

## 5. 对轨迹 / 映射的影响

- **竖直下降段**：柱坐标下 `Δr = Δφ = 0` —— 平凡直线（抓取下降天然简单）。
- **水平直线**：在笛卡尔是直线，在柱坐标是**曲线**，近轴处 `φ` 速率爆炸 ⇒ 平面移动须限制 `r` 下限。
- **手套映射**：方案 B 工作域已是 `(r, z, S1)`（`config.py` `GLOVE_SCH_B_WORK_*`）—— **本就是柱坐标**，天然自洽。
