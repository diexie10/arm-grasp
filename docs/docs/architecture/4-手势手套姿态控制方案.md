# 4-手势手套姿态控制方案（MPU6050 · v0.1 草案，待仿真验证）

> 状态：**草案**。调研已完成（lib-1，2026-09-10，来源见 §7），仿真验证未开始。
> 纪律：本方案通过仿真验证（§5 判据）后才允许动生产代码。
> 铁律约束：**固件零改动**、串口协议不动、安全层不旁路、无裸数字（参数进 config.py）。

## 1. 目标

戴手套的手实时控制 6 轴臂：手部姿态流（100Hz 传感）→ PC 映射 → M 命令流（20Hz）→ 现有舵机臂。
用于演示/教姿/预演，不替代视觉闭环抓取状态机。

## 2. 关键事实（本方案的地基，已核实源码）

- 固件 `M<n> <angle>` = **即时单轴覆盖**（cmd.c L143-160）：target/subgoal/current/vel 四件直接 snap + 立即 `Servo_SetAngle`，**无 busy 拒绝、无梯形滑行** → 20Hz 流式的平滑/限步/死区全部由 PC 端控制，固件照单执行。
- E 急停优先级最高（cmd.c L122：estop 时 M 直接拒绝）→ 手套模式的安全兜底不依赖任何新代码。
- 10s 命令超时 → 舵机 limp（既有机制）：手套断流时天然安全。

## 3. 架构决策

| ID | 决策 | 理由 | 否决项 |
|----|------|------|--------|
| AD-4a | 链路：手套 **ESP32 → WiFi UDP → PC**；同包格式可走 USB 有线 fallback（第二 COM 口） | 固件零改动；无"手套→STM32→PC→再串口回 STM32"的双跳回环；UDP 5-15ms 足够 | nRF24L01/HC-05 直连 STM32（需固件 SPI 驱动+转发，回环延迟 +50ms，nRF24 功耗/假货坑） |
| AD-4b | 滤波：手套端 **Mahony @100Hz** | 精度/延迟/算力平衡（lib-1 §1）；纯加速度计动态误差 >30° 不可用 | DMP（i2cdevlib 配置复杂）；Madgwick 略费算力（备选） |
| AD-4c | 映射位置：**PC 端**。手套只发滤波后欧拉角 + 原始数据诊断位 | 调参不刷机；调试台可视化观测；复用 kinematics 限位/IK | 手套端映射（每次调参重刷固件） |
| AD-4d | 控制语义：**方案 B 笛卡尔速度杆（手=摇杆）为主，方案 A 关节镜像为对照**，仿真对比裁决 | 竖直腕约束（J4=90−J2−J3）下自由手姿态无法 1:1 镜像；速度杆自动保持约束 | 直接镜像 S4 |
| AD-4e | 防抖：**20Hz 发送 + 0.5° 死区 + 每拍 ≤2° + EMA α=0.3** | lib-1 §4 推荐值，仿真标定后回填 config | 高频直通（MG996R 抖动/发热） |
| AD-4f | 安全：手套模式 = PC 端独立模式；**断流 500ms 冻结目标**；E 随时可发 | 新增风险面全部收在 PC；固件安全层不变 | — |
| AD-4g | S6 抓取：手套按钮或手势触发（仿真不验，装机定） | MPU6050 无指弯感知；弯曲传感器与"加速度方案"冲突 | 弯曲传感器 |
| AD-4h | 俯仰/偏航 → S1/S5 语义映射方向 | 待仿真实测直觉性 | — |

## 5. 仿真计划与通过判据

| 阶段 | 内容 | 通过判据 |
|------|------|----------|
| Sim1 滤波 | 合成 IMU 流（脚本轨迹+陀螺零偏+白噪声）→ Mahony → 欧拉角 | 静态段误差 <1°；动态跟踪 <3° |
| Sim2 映射 | 方案 A/B 同输入对比 → 关节目标 → 现有 kinematics 限位/IK | 限位零违例（映射内钳位）；抖动 std <0.3°/拍；B 方案 EE 轨迹无振荡 |
| Sim3 注入 | 合成流 → 映射 → DRY_RUN arm_serial → S 回读跟手 | 回读与目标偏差 <2°，无命令被拒 |

产出：`pc/glove/`（imu_filter.py / mapping.py / glove_sim.py）+ `out/trace.json` + 指标报告。
参数全部进 config.py `GLOVE_` 节。

## 6. 风险与诚实声明

- 仿真只验数值正确性，**手感（直觉性）必须真人实测**——"手=摇杆"的直觉假设未经人体验证。
- 映射增益/死区/中性区初值全部是推测值，装机后调。
- WiFi 干扰/丢包未测；家用 2.4G 拥塞时 UDP 表现未知。
- ESP32 到货前 Sim1-3 纯 PC 模拟，无真机依据；到货后先走有线 fallback 联调再上 WiFi。
- S6 触发方式未定案；S5（腕旋转）在方案 B 中的语义未定案。
- 本方案不改变抓取状态机（v2.0 流程原样）；手套模式是并行的手动控制通道。
