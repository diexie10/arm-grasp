# 外部调研 — 前沿机械臂代码设计（2026-08-21）

> 调研范围：LeRobot 生态 / STM32 舵机臂固件 / 视觉伺服（2025-2026）。
> 结论先行：硬件代差部分不适用；验证了状态机路线；STS3215 总线舵机是第二代明确答案。

## 一、不适用的（硬件代差）

| 方向 | 代表 | 原因 |
|------|------|------|
| LeRobot 全家桶 | SO-ARM100/SO-101 | 一切建立在 STS3215 总线舵机（位置反馈+一线串6个）上，MG996R 开环 PWM 学不了 |
| GraspNet 6-DoF 抓取 | reBot Jetson 版 | 需深度相机 + TensorRT |

| MoveIt2/ros2_control | illini RoboMaster | ROS 生态，PC 直连架构用不上 |

## 二、战略级发现：STS3215 是第二代答案

LeRobot 生态爆发证明 STS3215 总线舵机（~60元/个）正成为低成本机械臂事实标准。
恰好解决本项目最大架构遗憾（KNOWN_TRAPS #19 "S 命令无物理反馈"）：

- 一根线串 6 个（告别 6 路 PWM 布线）
- 有位置反馈 → wait_reached 从"自欺"变"可行"
- 12V 版堵转 30kg·cm（vs MG996R 9.4）
- LeRobot 生态直接兼容（遥操作/数据集/模仿学习现成）

升级路径：MG996R(PWM开环) → STS3215(UART总线)。不是现在换——先跑通 MG996R。
比 DS3218（仍是 PWM 开环）方向正确。

## 三、真亮点（可直接用）

### 1. so-arm101 运维手册（github.com/andymai/so-arm101）
实战踩坑工具集，四坑两条命中我们：
- 官方标称电源不够用（12V 2A 实际 brownout，社区共识 5A）→ 验证"官方电流标称不可信"，我们 8A+电容已保守
- set-protection 加速度限制削电流尖峰不削弱扭矩 → 与 MAX_ACC=15°/s² 同思想互证
- 连续关节失同步→追不可达目标→堵转→brownout 连锁 → ALIGN_MAX_ITER 上限防同款连锁
- 数字孪生可视化（Rerun 幽灵叠加+同步曲线）→ 联调可视化可借鉴

### 2. VisionTouch（github.com/shrirag10/VisionTouch）IBVS 三教训
- **轴反转陷阱**：朝下的腕部相机镜像世界系，速度映射不改符号会背离目标 → SERVO_KP 符号待实测的理论依据
- **假收敛过滤**：低置信度检测拒绝执行防盲降 → LOST_FRAME_THRESHOLD 同款
- **相机 FOV**：90° 才够，60° 桌面边缘有盲区 → 采购硬指标

### 3. UTwente 2026 硕士论文（YOLOv11 + Franka 形状分选）
同感知下对比解析状态机 vs RL 策略：
- **解析方法赢**——RL 零样本只做好到达粗放置，接触阶段全失败
- 解析靠螺旋搜索补偿残余对准误差完成全部任务
- 对称物体朝向从视觉本质上难恢复（再证 OBB 对正方形无意义）
- **落地：DESCEND 未触发红外时螺旋微搜索已实现（state_machine._spiral_search）**

### 4. illini RoboMaster Engineer2026（ROS2 UART 协议细节）
- command_timeout_s=0.5 重发最后位置喂看门狗 = hold-on-timeout 哲学
- 我们是 limp-on-timeout（防失控优先）。抓木块掉不了啥、失控会扫桌 → limp 正确，记录差异即可
- send_rate ≤20Hz 防 DMA 过载 = 我们 DT_MS=20ms ✓
- joint_sign_flip[] + gear_ratio[] 每关节配置 = JOINT_OFFSET 同构

### 5. DevClaw-Robot（github.com/sjkncs/DevClaw-Robot，Dummy Robot 衍生）
STM32F4+F1+CAN，7 阶段算法栈 = pc/ 目录未来演进地图：
- 已有对应：状态机/安全监控雏形/S 曲线
- 近期可抄：最小 jerk 轨迹（五次多项式端点加速度连续）、运动学标定器（DH 偏移+数值雅可比）
- 远期（需闭环电机）：抗扰观测器/摩擦补偿/阻抗控制
- 遥测双模式（二进制 CRC-16 + ASCII CSV 可配）值得记住

### 6. RegexCore/stm32-robot-arm-controller
STM32F446+PCA9685+舵机（2026-03）：依赖注入/C驱动与C++应用分层/100Hz 确定性控制环。
