## 1. 视觉伺服（IBVS）工程实践

### 已做对（被外部资料验证）
| 做法 | 原理/来源 |
|---|---|
| 5°/步限幅 | = 饱和函数 sat(·)，标准防振荡手段（CN116533249A：固定增益+无饱和在期望位姿抖动无法精确定位，加饱和后 18.6s→4.3s） |
| 纯 P + 限幅 + 到位死区，不加 I | 慢视觉 + I 项必积分饱和/极限环（Corke 1995） |
| settle 1s（停-看-动） | 慢视觉环（300ms 周期）只能 look-and-move，不能连续伺服；settle = 等效时延补偿（谢晖 2006 Smith 预估） |
| 单向逼近消隙 | 回差只在换向时显现，恒同方向逼近 = 零成本消隙（OmArm 实测 + 机械常识） |
| 逐级下降 + 每级重新对齐 | 规避像素→关节直接映射在深度变化时失稳的问题（误差正比于深度，深度变 Kp 就失效）；每级伺服时深度近似不变 |

### 需要微调（真机必测）
1. **收敛死区 ≥ 2°**：MG996R 实测重复精度 ±2~3°（非标称 0.5°），<2° 的修正被回差吞掉 → 原地抖动。ALIGN_PX_TOL=20px（Kp=0.15→3°）够；**FINAL_ALIGN_MAX_STEP=2.0° 在死区边缘，可能调到 2.5°**
2. 像素→关节映射保留 Kp=0.15 + 深度归一（只在需要时做，当前"每级对齐"已规避）

### 可参考开源项目
- `Cedric-Loic/ros2-ur3e-vision-sorting`：YOLO-OBB + eye-in-hand + 分拣（最像）
- `jjjadand/reBot-DevArm-Grasp`：冻结帧→变换→运动（look-and-move 架构）
- `lxynari25-arch/Z1arm_Yolo_Grasp`：6DOF + eye-in-hand + YOLO，像素→深度→相机→基座变换链

### 明确过度工程（不做）
- DDPG/在线雅可比自适应增益（与 300ms 周期不兼容）
- 给 MG996R 加编码器（贵、拆机、只读位置不除回差）
- FOC/无刷/行星减速升级（±0.02° 对 3.5cm 方块纯属过度）

## 2. MG996R 精度与可靠性

### 实测数据（关键换算）
- MG996R 重复精度 ±2-3°，**2° × 25cm 臂长 ≈ 末端 8.7mm**（"±1cm"说法的来源）
- 影响精度因素排序：**回差 > 结构刚度/负载变形 > 舵机分辨率**（分辨率 ±2° 已够，不是瓶颈）
- 精度结论：**同方向重复精度远好于绝对精度** → 单向逼近是最高性价比手段

### 供电铁律（炸机高发区，再次确认）
- 6 舵机空载 ~1.2A、**峰值可达 12A** → 独立 5V/15A 电源 + **每舵机并联 1000µF 电容** + AWG18 粗线
- 电压严控 4.8-6V（超压烧电机，堵转 ~2.5A）
- 舵机电源与 STM32 完全隔离、仅共地（已有铁律）

### 抓 3.5cm 方块的容差策略（新决策）
- 目标只需 ±5mm 容差（方块 35mm，夹爪开口 45-50mm 即有 5-7mm 单边容差）
- 投资优先级：①独立电源+电容+粗线（消除抖动）②单向逼近（消除回差，已做）③**刚性夹爪开口 45-50mm + 倒角爪口 + 硅胶/TPU 指垫**（5-10mm 误差都能抓住）④视觉"下探-确认-微调"闭环（已做）⑤**电流采样力检测**（STM32 ADC 读舵机电流判断夹住即停，廉价顺手加）
- 实测：刚性平行爪 ±0.8mm 稳定；纯柔性爪回弹 ±3.2mm；**刚性爪体+硅胶指垫最佳**

### 失效模式
- 抖舵/烧毁三主因：供电不足（电压跌落）、信号干扰/电位器老化、过压
- 虚位来源：机械回差为主 + 塑料外壳安装孔用久撑成椭圆形（输出轴晃动）

## 3. 数据扩增（录像抽帧方案具体参数）

### 抽帧参数
- **1s 间隔抽帧**（连续帧 SSIM≈1.0，全帧训练有害且浪费标注预算）
- **Laplacian 方差 ≥30 过滤**（<10 严重模糊必扔；30-100 可接受；>100 非常清晰）
- 抽帧质检通过率控制在 40-60%（太低过严、太高混入差帧）
- 动态片段（相机下降时）多抽，静止片段少抽

### 尺度分布（针对"近景 >25% 掉 conf"）
- 当前 231 张几乎全远景 = 模型没见过近景 = 分布外 → 必须真实近景样本
- scale 增强（默认 0.5，即 0.5×-1.5×）覆盖不了 10 倍尺度差 → **近景（占比>25%）占 500-600 张，远景 300-400 补足**
- 训练参数：`multi_scale=0.25`、**近景时 mosaic 降到 0.3-0.5**（大目标会被 mosaic 拼贴边界切掉）、`close_mosaic=50`（末尾用原始近景微调）、推理 imgsz 与训练一致且用较高值（1024-1280）

### 伪标签（半自动标注）
- **conf≥0.5 激进过滤**（案例：8506→18608 张性能反降，砍 60% 低置信后 mAP50 +6.9%——噪声伪标签伤大于益）
- 进阶：双阈值 + 伪标签降权 w=0.1-0.5 + 从最优权重 fine-tune
- **角度必须人工核对**：伪标签最常见错误是角度/边界，OBB 角度错 = 框失效（对应我们 θ 精度要求）
- 原标注不进验证集，验证集保持纯人工标注
- 工具：LabelMe（原生 OBB + 导出 YOLO-OBB）、X-AnyLabeling

### YOLO-OBB 特殊要求
- 角度约定：标签规范化为"长边"形式，弧度 [-45°,135°)，w 是长边
- 角度损失：默认训练易让模型"学到 0° 旋转"（角度不被损失惩罚），必要时手动加 ang=5.0 角度损失
- 旋转框角点越界：裁剪到边界，容差仅 0.02-0.05（不要放宽 assert 掩盖错误标注）
