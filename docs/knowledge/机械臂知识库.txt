## 一、系统总体架构

**核心思路**：Windows PC 作大脑（视觉推理 + 决策），YOLO 作眼睛（目标检测），红外对管作触觉（抓取确认），STM32 作神经与肌肉（舵机执行），低成本 6 轴机械臂作手脚。

**分层设计**：

| 层级 | 功能 | 核心组件 |
|---|---|---|
| **感知层** | 视觉识别 + 触觉确认 | USB摄像头 / 手机DroidCam + YOLO11n + 红外对射传感器 |
| **决策层** | 目标定位 + 运动规划 | Windows PC（RTX 4060）+ Python + Ultralytics |
| **控制层** | 指令解析 + PWM生成 | STM32F103C8T6（USB CDC虚拟串口） |
| **执行层** | 关节驱动 + 抓取动作 | 6×MG996R舵机 + 6V 8A独立电源 |
| **供电层** | 隔离供电 + 共地 | 舵机独立6V 8A，STM32由USB供电，两者共地 |

**工作流程**：YOLO粗定位（XY）→ 串口发角度指令 → 机械臂移动到目标上方 → 逐层下降 + 十字扫动 → 红外对管遮断触发 → 夹爪收紧 → 抓取完成。Z轴不靠测量，靠“物理接触确认”。

**参考架构项目**：
- **JetArm**（Hiwonder/JetArm）：NVIDIA Jetson做视觉推理 + STM32控制板做舵机驱动，3D视觉+ROS
- **DOFBOT-SE**（sw-shar/Robot-DOFBOT-SE）：6DOF机械臂，ROS2+Python编程，STM32控制器驱动
- **reBot-DevArm-Grasp**（Seeed-Projects/reBot-DevArm-Grasp）：YOLO/OBB抓取管道，RGB-D深度相机，完整视觉抓取演示

| 部件 | 型号/规格 | 价格 | 关键说明 |
|---|---|---|---|
| 机械臂本体 | 6DOF铝合金支架 + 6×MG996R | 已有 | 到手散件，需自行组装 |
| 主控 | STM32F103C8T6最小系统板 | ~10元 | Blue Pill，定时器直驱6路PWM |
| 电源 | 6V 8A开关电源适配器 | ~20元 | MG996R甜点电压（4.8-6.6V），比5V更优 |
| 红外对管 | 对射式50cm | ~10元 | 夹爪两侧安装，940nm对木头100%遮挡 |
| 摄像头 | 前期手机DroidCam / 后期USB 1080P可调焦 | 0~30元 | 选无畸变镜头，不要鱼眼 |
| 杜邦线 | 公对公/母对母 | ~5元 | 舵机电源线建议20AWG/18AWG粗线 |

**不需要买的**：舵机驱动板（PCA9685）——STM32定时器足够；CH340串口模块——用板载USB CDC虚拟串口。

**关键供电方案**：
```
6V 8A电源 ──┬── 6个舵机VCC（并联）
             └── 舵机GND ──┐
                           ├── 共地（必须！）
电脑USB ──→ STM32（供电+通信）── GND ──┘
```
严禁将舵机电源接STM32的3.3V或5V引脚。

## 四、STM32固件开发（已完成，编译通过）

**工程路径**：`C:\Users\diexie\Desktop\arm-grasp\`

### 4.1 功能实现
- **USB CDC虚拟串口**：插USB即识别为COM口，同时供电，无需CH340
- **6路舵机PWM**：TIM1（PA8/PA9/PA10）+ TIM2（PA0/PA1/PA2），50Hz，脉宽0.5-2.5ms
- **红外对管读取**：PB12/PB13，高低电平检测
- **串口指令解析**：
  - `M<n> <angle>\r\n`（n=1..6，单舵机）
  - `MALL <angle>\r\n`（全部舵机）
  - `I\r\n`（查询红外状态 → `IR1=0 IR2=1`）
  - `S\r\n`（查询舵机角度 → `S1=90 S2=45...`）
  - 非法指令 → `ERR`

### 4.2 编译状态
- **Keil MDK-Lite**（32KB限制），编译通过（0 Errors, 0 Warnings）
- **代码体积**：16.97kB（远低于32KB限制）
- **参考工程**：`shiguangqianmo/6-DOF-Manipulator`

### 4.3 关键代码片段（PWM配置）
```c
// 50Hz, 20ms周期
TIM_HandleTypeDef htim1;
htim1.Instance = TIM1;
htim1.Init.Prescaler = 71;      // 72MHz/72 = 1MHz
htim1.Init.Period = 19999;      // 20ms
htim1.Init.CounterMode = TIM_COUNTERMODE_UP;
// 脉宽：0.5ms=500 → 0°，2.5ms=2500 → 180°
```

## 五、调参经验与核心避坑

### 5.1 舵机PWM精度
- 计数分辨率决定角度精度：`ARR=1999, PSC=719`（每计数10us）比`ARR=199, PSC=7199`（每计数1us但只有200个点）更优
- 对应关系：**0.5ms = 0°，1.5ms = 90°，2.5ms = 180°**
- 启用ARR预装载（ARPE=1），确保多通道同步更新

### 5.2 舵机抖动五大根源及解决

| 根源 | 表现 | 解决方案 |
|---|---|---|
| **电源不足**（最常见） | 多舵机同时动作时电压骤降 | 独立6V 8A电源 + 4700μF电容 |
| **PWM频率不稳定** | 舵机抽搐、不受控 | 确认定时器50Hz，检查时钟源 |
| **阶梯状轨迹** | 角度跳变引发高频抖动 | S型加减速曲线平滑过渡 |
| **死区阈值过大** | 低速抖动明显 | 死区设为1°，50-100Hz非阻塞更新 |
| **信号干扰** | 长距离PWM线引入畸变 | 缩短信号线、加磁环、避免与电源线平行 |

### 5.3 电源滤波（进阶）
- 每个舵机VCC/GND之间焊接**100uF电解电容 + 0.1uF陶瓷电容**
- STM32每个VDD/VSS引脚旁放置**100nF陶瓷电容**
- 电位器输出端加**RC低通滤波**（R=1kΩ，C=100nF，截止频率~1.6kHz）

### 5.4 逆运动学调参
- **DH参数理论占30%，实际测量占70%**：关节0.5mm间隙 → 末端3cm偏差
- **实测四步法**：基准面确定 → 连杆长度测量 → 扭角测量 → 偏移量校准（激光笔辅助）
- **验证技巧**：末端装激光笔，移动5个位置，记录偏差，最小二乘法优化DH参数
- **参考工具**：OPW Kinematics Solver（解析逆运动学库，参数由机器人规格表的7个主值和关节零偏移量决定）

## 六、常见问题与排障

### 6.1 机械结构
- **组装**：不要一上来拧死螺丝——先让关节有轻微晃动，手动测试顺滑度，确认无卡顿后再锁死
- **线材**：杜邦线接触不良 → 改插针焊接 + 热缩管 + 线缆固定

### 6.2 视觉抓取
- **相机标定**：四点标定验证像素→毫米映射
- **手眼标定**：Eye-to-Hand通过点对应+SVD求解
- **抓取姿态**：采样范围要覆盖物体所有可能朝向

### 6.3 舵机堵转
- MG996R堵转电流可达1A以上
- 代码中加入**软限位**，防止转到物理极限之外
- 考虑加入电流监测，检测到堵转自动停止

### 6.4 多路不同步
- 启用ARR预装载
- 单点接地、星型拓扑
- PWM走线尽量短且平行

1.2 设计哲学
原则   具体实现
PC做大脑，MCU做脊髓   所有智能决策（视觉、规划、状态机）在PC；STM32只做实时PWM输出和传感器读取

视觉用eye-to-hand   固定俯视摄像头，避免末端相机带来的振动、负载、扫描问题

粗定位+精确认   YOLO粗定位XY（±5mm）→ 单方向逼近消虚位 → 红外对管物理确认Z轴

无需完整6轴IK   atan2解析解 + 查表插值 + 教学标定，5轴即可满足竖直抓取

低成本优先   总硬件¥45~75，不追求工业精度，追求"能跑通全流程"

软件补偿硬件   虚位用单方向逼近补偿，标定误差用四点标定修正

2.2 电源设计（关键！）

2.2.1 为什么必须独立供电

问题：6个MG996同时启动
  瞬态电流 = 6 × 2.5A = 15A（峰值）
  你的电源 = 6V × 8A = 48W（持续）

如果USB供电（500mA）给舵机：
  → 电压瞬间拉低到2V以下
  → STM32复位
  → 舵机失控
  → 可能打坏机械结构

2.2.2 正确接线方案

6V 8A开关电源
  ├── VCC(6V) ──→ 舵机排（6个MG996的VCC并联）
  │                ├── 470μF电解电容（靠近电源输出端）
  │                ├── 每个舵机VCC脚并联100μF电容
  │                └── 100nF陶瓷电容（高频滤波）
  │
  ├── GND ──────→ 舵机GND ──→ STM32 GND（必须共地！）
  │
  └── 注意：6V电源的GND 和 USB的GND 必须连接！
            否则PWM信号参考电平漂移 → 舵机抖动/不响应

USB（PC）
  ├── 5V ──→ STM32 3.3V LDO ──→ MCU供电
  ├── D+ ──→ PA12 (USB DP)
  ├── D- ──→ PA11 (USB DM)
  └── GND ──→ STM32 GND ←──→ 6V电源GND（共地点）

3.4 虚位（Backlash）的物理本质

MG996齿轮传动链：
  电机齿轮(12T) → 中间齿轮(24T) → 输出齿轮(48T)
  
  每级间隙 ≈ 0.1mm
  总输出轴间隙 ≈ 0.3mm
  换算到角度 ≈ ±3°~8°（取决于负载方向）
  
  表现：
  正转到位后，反转3°~8°无响应
  同一目标角度，从CW方向和CCW方向到达，位置不同
  末端累积误差 = 各关节虚位 × 力臂长度
  6轴累积 → 末端 ±10mm（这就是你的物理极限）

4.2 USB CDC 固件层实现要点

// usbd_cdc_if.c 中的关键回调

// 接收回调（中断上下文）
static int8_t CDC_Receive_FS(uint8_t* Buf, uint32_t* Len) {
    // ⚠️ 铁律1：这里只做memcpy，不做任何耗时操作
    ring_buffer_write(&rx_ring, Buf, *Len);
    
    // ⚠️ 铁律2：必须重新使能接收，否则只收一包就断！
    USBD_CDC_SetRxBuffer(&hUsbDeviceFS, &rx_buf[0]);
    USBD_CDC_ReceivePacket(&hUsbDeviceFS);
    
    return USBD_OK;
}

// 发送函数（主循环调用）
void CDC_Send(const uint8_t* data, uint16_t len) {
    // ⚠️ 铁律3：超过64字节必须分包
    while (len > 0) {
        uint16_t chunk = (len > 64) ? 64 : len;
        while (CDC_Transmit_FS((uint8_t*)data, chunk) == USBD_BUSY) {
            // 等待端点空闲，但不能死等
            HAL_Delay(1);
            timeout_counter++;
            if (timeout_counter > 100) {
                usb_reconnect();  // USB异常，重连
                return;
            }
        }
        data += chunk;
        len -= chunk;
    }
}

4.6 上位机 Python 串口通信

import serial
import time
import threading
from collections import deque

class ArmSerial:
    def init(self, port, baudrate=115200):
        self.ser = serial.Serial(
            port=port,
            baudrate=baudrate,
            timeout=0.1,          # ⚠️ 必须设超时，否则readline永久阻塞
            write_timeout=0.1
        )
        self.rx_buffer = deque(maxlen=100)
        self.lock = threading.Lock()
        self.running = True
        # 启动接收线程
        self.rx_thread = threading.Thread(target=self._rx_loop, daemon=True)
        self.rx_thread.start()
    
    def _rx_loop(self):
        """接收线程：持续读取，不在主线程阻塞"""
        while self.running:
            try:
                line = self.ser.readline().decode('utf-8').strip()
                if line:
                    self.rx_buffer.append(line)
            except serial.SerialException:
                time.sleep(0.5)  # USB断开，等待重连
    
    def send_angle(self, servo_id, angle):
        """发送舵机角度命令"""
        angle = max(0, min(180, angle))  # ⚠️ 钳位！
        cmd = f"M{servo_id} {angle}rn"
        with self.lock:
            self.ser.write(cmd.encode())
    
    def send_command(self, cmd):
        with self.lock:
            self.ser.write((cmd + "rn").encode())
    
    def read_response(self, timeout=0.5):
        """非阻塞读取响应"""
        start = time.time()
        while time.time() - start < timeout:
            if self.rx_buffer:
                return self.rx_buffer.popleft()
            time.sleep(0.01)
        return None
    
    def close(self):
        self.running = False
        self.ser.close()

4.7 pyserial 常见坑
问题   原因   解法
readline() 永久阻塞   未设timeout   serial.Serial(..., timeout=0.1)

打开端口报 PermissionError   Linux下权限   sudo chmod 666 /dev/ttyACM0 或加udev规则

Windows识别为"未知设备"   CDC驱动未加载   等5秒自动装；或设备管理器手动指定usbser.sys

发送后无响应   rn未真正发出   用ser.write(b"M1 90rn")而非print

高速发送丢包   PC发送太快，MCU缓冲满   等MCU回OK再发下一条

5.2 主循环状态机

// main.c
typedef enum {
    STATE_IDLE,       // 等待命令
    STATE_MOVING,     // 舵机运动中（插补）
    STATE_QUERY,      // 响应查询
    STATE_ERROR       // 错误状态
} MainState;

int main(void) {
    HAL_Init();
    SystemClock_Config();  // 72MHz
    MX_GPIO_Init();        // 红外输入
    MX_TIM1_Init();        // PWM CH1-CH4
    MX_TIM2_Init();        // PWM CH1-CH2
    MX_USB_DEVICE_Init();  // CDC
    
    MainState state = STATE_IDLE;
    
    while (1) {
        // 1. 解析环形缓冲区中的命令
        if (ring_buffer_available()) {
            parse_and_execute_command();
        }
        
        // 2. 如果正在运动，执行插补
        if (state == STATE_MOVING) {
            interpolation_step();  // 每20ms一步
        }
        
        // 3. 周期性读取红外（每1ms）
        if (HAL_GetTick() - last_ir_read > 1) {
            ir_update();
            last_ir_read = HAL_GetTick();
        }
        
        // 4. 超时保护
        if (HAL_GetTick() - last_command_time > 10000) {
            // 10秒无命令 → 安全停止
            all_servos_hold();
            state = STATE_IDLE;
        }
    }
}

// servo.c
// TIM1: 舵机1-4 (PA8, PA9, PA10, PA11→注意PA11是USB！改用PB13)
// 实际分配：
//   TIM1_CH1 = PA8  → 舵机1 (J1底座)
//   TIM1_CH2 = PA9  → 舵机2 (J2大臂)
//   TIM1_CH3 = PA10 → 舵机3 (J3小臂)
//   TIM1_CH4 = PB13 → 舵机4 (J4腕部) [重映射，避开PA11 USB]
//   TIM2_CH1 = PA0  → 舵机5 (J5旋转)
//   TIM2_CH2 = PA1  → 舵机6 (J6夹爪)

void Servo_Init(void) {
    // TIM1配置
    TIM1->PSC = 72 - 1;       // 72MHz / 72 = 1MHz计数频率
    TIM1->ARR = 20000 - 1;    // 1MHz / 20000 = 50Hz (20ms周期)
    TIM1->CCMR1 = (6 << 4) | (1 << 3);  // PWM模式1，预装载使能
    TIM1->CCMR2 = (6 << 4) | (1 << 3);
    TIM1->CCER = 0x000F;      // CH1-CH4输出使能，高电平有效
    TIM1->BDTR = 0x8000;      // 主输出使能（高级定时器必须！）
    TIM1->CR1 = 0x0001;       // 启动定时器
    
    // TIM2配置（同理）
    TIM2->PSC = 72 - 1;
    TIM2->ARR = 20000 - 1;
    TIM2->CCMR1 = (6 << 4) | (1 << 3);
    TIM2->CCER = 0x0003;      // CH1-CH2
    TIM2->CR1 = 0x0001;
}

void Servo_SetAngle(uint8_t id, float angle) {
    // 角度钳位
    if (angle < SERVO_MIN[id]) angle = SERVO_MIN[id];
    if (angle > SERVO_MAX[id]) angle = SERVO_MAX[id];
    
    // 角度→脉宽：500 + (angle/180) * 2000
    uint16_t pulse = (uint16_t)(500 + (angle / 180.0f) * 2000.0f);
    
    switch(id) {
        case 0: TIM1->CCR1 = pulse; break;
        case 1: TIM1->CCR2 = pulse; break;
        case 2: TIM1->CCR3 = pulse; break;
        case 3: TIM1->CCR4 = pulse; break;
        case 4: TIM2->CCR1 = pulse; break;
        case 5: TIM2->CCR2 = pulse; break;
    }
}

define IR_PIN_2  GPIO_PIN_1
define IR_PORT   GPIOB

void IR_Init(void) {
    GPIO_InitTypeDef GPIO_InitStruct = {0};
    GPIO_InitStruct.Pin = IR_PIN_1 | IR_PIN_2;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_PULLUP;  // 内部上拉

}

// ⚠️ 去抖：5次采样中3次以上触发才算有效
uint8_t IR_Read_Debounced(uint8_t channel) {
    uint16_t pin = (channel == 0) ? IR_PIN_1 : IR_PIN_2;
    uint8_t count = 0;
    for (int i = 0; i < 5; i++) {
        if (HAL_GPIO_ReadPin(IR_PORT, pin) == GPIO_PIN_RESET) {
            count++;
        }
        // 短延时（用NOP而非HAL_Delay，避免阻塞）
        for (volatile int j = 0; j < 1000; j++);  // ~1ms @72MHz
    }
    return (count >= 3) ? 1 : 0;
}

import numpy as np

def inverse_kinematics(x_target, y_target, z_target, 
                       L1=50, L2=120, L3=100):
    """
    输入：目标点桌面坐标 (mm)
    输出：6个关节角度 (度)
    
    L1: 底座到J2轴高度 (mm)
    L2: 大臂长度 (mm)
    L3: 小臂长度 (mm)
    """
    # ─── Step 1: J1 底座旋转 ───
    theta1 = np.arctan2(y_target, x_target)  # 弧度
    
    # ─── Step 2: 在垂直平面内解 J2, J3 ───
    # 将3D问题降为2D（在J1旋转后的平面内）
    r = np.sqrt(x_target2 + y_target2)  # 水平距离
    z = z_target - L1                        # 相对J2的高度
    
    # 余弦定理
    D = (r2 + z2 - L22 - L32) / (2 * L2 * L3)
    D = np.clip(D, -1, 1)  # 数值安全
    
    theta3 = np.arccos(D)  # J3角度（肘部）
    
    # J2角度
    alpha = np.arctan2(z, r)
    beta = np.arctan2(L3 * np.sin(theta3), L2 + L3 * np.cos(theta3))
    theta2 = alpha + beta
    
    # ─── Step 3: J4 保持末端竖直 ───
    theta4 = np.pi/2 - theta2 - theta3  # 使夹爪朝下
    
    # ─── Step 4: J5, J6 固定值（教学标定）───
    theta5 = np.pi/2  # 90°，固定
    theta6 = 90       # 夹爪初始角度
    
    # 弧度→度
    angles = np.array([theta1, theta2, theta3, theta4, theta5, theta6])
    angles_deg = np.degrees(angles)
    
    return angles_deg

7.1 S曲线轨迹规划

class SCurveTrajectory:
    """7段S曲线：加加速→加速→匀速→减速→减减速"""
    
    def init(self, start, end, max_vel=30.0, max_acc=15.0, dt=0.02):
        """
        start, end: 起始/目标角度（度）
        max_vel: 最大角速度 (°/s) → MG996带载极限60°/s的50%
        max_acc: 最大角加速度 (°/s²)
        dt: 插补周期 20ms（与PWM周期对齐）
        """
        self.start = start
        self.end = end
        self.max_vel = max_vel
        self.max_acc = max_acc
        self.dt = dt
        self.distance = abs(end - start)
        
        # 计算总时间
        t_acc = max_vel / max_acc
        d_acc = 0.5 * max_acc * t_acc**2
        
        if 2 * d_acc >= self.distance:
            # 三角形曲线（达不到最大速度）
            t_acc = np.sqrt(self.distance / max_acc)
            self.total_time = 2 * t_acc
        else:
            # 梯形曲线
            d_cruise = self.distance - 2 * d_acc
            t_cruise = d_cruise / max_vel
            self.total_time = 2 * t_acc + t_cruise
    
    def get_position(self, t):
        """给定时间t，返回插补角度"""
        # 简化版：梯形速度曲线
        t_acc = min(self.max_vel / self.max_acc, self.total_time / 2)
        
        if t < t_acc:
            # 加速段
            pos = 0.5 * self.max_acc * t**2
        elif t < self.total_time - t_acc:
            # 匀速段
            pos = 0.5 * self.max_acc * t_acc**2 + self.max_vel * (t - t_acc)
        else:
            # 减速段
            t_rem = self.total_time - t
            pos = self.distance - 0.5 * self.max_acc * t_rem**2
        
        pos = min(pos, self.distance)
        direction = 1 if self.end > self.start else -1
        return self.start + direction * pos

class BacklashCompensator:
    """
    来源：AR4、SO-100、GELLO 项目验证
    原理：MG996齿轮间隙±3°~8°，换向时无响应
    策略：永远从同一方向逼近目标
    """
    
    OVERSHOOT_DEG = 15  # 过冲角度
    
    def init(self, serial_port):
        self.ser = serial_port
        self.last_direction = [1] * 6  # 默认CW
    
    def move_to(self, servo_id, target_angle, approach_direction='cw'):
        """
        单方向逼近：
        先过冲15°（从目标远离方向）
        再从指定方向回到目标
        """
        if approach_direction == 'cw':
            overshoot = target_angle + self.OVERSHOOT_DEG
        else:
            overshoot = target_angle - self.OVERSHOOT_DEG
        
        # 钳位
        overshoot = max(0, min(180, overshoot))
        
        # Step 1: 过冲
        self.ser.send_angle(servo_id, overshoot)
        self._wait_reached(servo_id, overshoot)
        
        # Step 2: 从指定方向逼近
        self.ser.send_angle(servo_id, target_angle)
        self._wait_reached(servo_id, target_angle)
        
        self.last_direction[servo_id] = 1 if approach_direction == 'cw' else -1
    
    def _wait_reached(self, servo_id, target, timeout=2.0):
        """等待舵机到位（非阻塞轮询）"""
        start = time.time()
        while time.time() - start < timeout:
            # 查询当前角度
            self.ser.send_command('S')
            resp = self.ser.read_response(timeout=0.1)
            if resp and resp.startswith('ANG:'):
                angles = [float(x) for x in resp[4:].split(',')]
                if abs(angles[servo_id] - target) < 1.0:  # 1°容差
                    return True
            time.sleep(0.05)
        return False  # 超时

from ultralytics import YOLO

class VisionSystem:
    def init(self, model_path="best.pt", camera_id=0):
        self.model = YOLO(model_path)
        self.conf_threshold = 0.6
        self.iou_threshold = 0.45
        
        # 打开摄像头
        self.cap = cv2.VideoCapture(camera_id)
        self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)
        self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)
        
        # 预热（首次推理1.9s，CUDA kernel编译）
        self._warmup()
        
        # 标定矩阵（初始化时设置）
        self.homography_matrix = None
    
    def _warmup(self):
        """预热：消除首次推理延迟"""
        dummy = np.zeros((640, 640, 3), dtype=np.uint8)
        self.model.predict(dummy, verbose=False)
        print("Vision warmup done.")
    
    def detect(self, frame):
        """
        输入：BGR帧 (H×W×3)
        输出：检测结果列表 [{bbox, center_px, confidence}]
        """
        results = self.model.predict(
            frame,
            conf=self.conf_threshold,
            iou=self.iou_threshold,
            verbose=False
        )
        
        detections = []
        for r in results:
            for box in r.boxes:
                x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
                conf = float(box.conf[0])
                cx = (x1 + x2) / 2
                cy = (y1 + y2) / 2
                detections.append({
                    'bbox': (int(x1), int(y1), int(x2), int(y2)),
                    'center_px': (cx, cy),
                    'confidence': conf
                })
        
        return detections
    
    def pixel_to_world(self, px, py):
        """像素坐标 → 桌面毫米坐标"""
        if self.homography_matrix is None:
            raise RuntimeError("未标定！请先执行四点标定")
        
        pt = np.array(], dtype=np.float32)
        world_pt = cv2.perspectiveTransform(pt, self.homography_matrix)
        return world_pt[0][0]  # (x_mm, y_mm)
    
    def read_frame(self):
        """读取一帧（支持中文路径的替代方案）"""
        ret, frame = self.cap.read()
        if not ret:
            return None
        return frame

class IRSensor:

        """读取红外状态（通过串口查询STM32）"""
        self.ser.send_command('I')
        resp = self.ser.read_response(timeout=0.2)
        if resp and resp.startswith('IR:'):
            states = resp[3:].split(',')
            return [int(s) for s in states]
        return [0, 0]  # 默认无触发
    
    def is_triggered(self):
        """持续触发判定（非单次）"""
        states = self.read()
        if any(s == 1 for s in states):
            self.trigger_count += 1
        else:
            self.trigger_count = 0
        
        return self.trigger_count >= self.trigger_threshold

10.2 Python实现

import time
from enum import Enum

class GraspState(Enum):
    IDLE = 0
    APPROACH = 1
    DESCEND = 2
    GRIP = 3
    TRANSPORT = 4
    RELEASE = 5
    ERROR = 6

class GraspStateMachine:
    def init(self, arm_serial, vision, ir_sensor):
        self.arm = arm_serial
        self.vision = vision
        self.ir = ir_sensor
        self.state = GraspState.IDLE
        self.timeout_map = {
            GraspState.APPROACH: 10.0,   # 秒
            GraspState.DESCEND: 15.0,
            GraspState.GRIP: 5.0,
            GraspState.TRANSPORT: 10.0,
            GraspState.RELEASE: 5.0,
        }
        self.state_start_time = 0
        self.log = []
    
    def _enter_state(self, new_state):
        self.log.append(f"[{time.time():.3f}] {self.state.name} → {new_state.name}")
        self.state = new_state
        self.state_start_time = time.time()
    
    def _check_timeout(self):
        timeout = self.timeout_map.get(self.state, 30.0)
        if time.time() - self.state_start_time > timeout:
            self._enter_state(GraspState.ERROR)
            return True
        return False
    
    def update(self):
        """主循环调用，每20ms一次"""
        if self._check_timeout():
            self._error_recovery()
            return
        
        if self.state == GraspState.IDLE:
            self._do_idle()
        elif self.state == GraspState.APPROACH:
            self._do_approach()
        elif self.state == GraspState.DESCEND:
            self._do_descend()
        elif self.state == GraspState.GRIP:
            self._do_grip()
        elif self.state == GraspState.TRANSPORT:
            self._do_transport()
        elif self.state == GraspState.RELEASE:
            self._do_release()
        elif self.state == GraspState.ERROR:
            self._error_recovery()
    
    def _do_idle(self):
        frame = self.vision.read_frame()
        if frame is None:
            return
        detections = self.vision.detect(frame)
        if detections:
            best = max(detections, key=lambda d: d['confidence'])
            self.target_px = best['center_px']
            self.target_mm = self.vision.pixel_to_world(*self.target_px)
            self._enter_state(GraspState.APPROACH)
    
    def _do_approach(self):
        # 计算IK
        x, y = self.target_mm
        angles = inverse_kinematics(x, y, Z_SAFE)  # Z_SAFE=100mm
        
        # 单方向逼近XY
        for i in range(4):  # J1-J4
            self.arm.move_to(i, angles[i], direction='cw')
        
        # 等待500ms（振动衰减）
        time.sleep(0.5)
        self._enter_state(GraspState.DESCEND)
    
    def _do_descend(self):
        # 逐层下降，每层5mm
        current_z = Z_SAFE
        while current_z > 0:
            current_z -= 5
            angles = inverse_kinematics(*self.target_mm, current_z)
            self.arm.send_angles(angles[:4])
            time.sleep(0.3)  # 等稳定
            
            # 检查红外
            if self.ir.is_triggered():
                self._enter_state(GraspState.GRIP)
                return
        
        # 到达桌面仍未触发
        self._enter_state(GraspState.ERROR)
    
    def _do_grip(self):
        self.arm.send_angle(5, 120)  # 夹爪闭合
        time.sleep(0.2)              # 等夹持稳定
        # 提升到安全高度
        angles = inverse_kinematics(*self.target_mm, Z_SAFE)
        self.arm.send_angles(angles[:4])
        time.sleep(1.0)
        self._enter_state(GraspState.TRANSPORT)
    
    def _do_transport(self):
        # 移动到放置位
        angles = inverse_kinematics(*PLACE_POS, Z_SAFE)
        self.arm.send_angles(angles[:4])
        time.sleep(1.0)
        self._enter_state(GraspState.RELEASE)
    
    def _do_release(self):
        self.arm.send_angle(5, 30)  # 夹爪张开
        time.sleep(0.3)
        self._enter_state(GraspState.IDLE)
    
    def _error_recovery(self):
        """安全回退：先抬Z，再回HOME"""
        self.arm.send_angle(5, 30)  # 松开夹爪
        time.sleep(0.3)
        self.arm.send_command('H')  # 全部回中位
        time.sleep(2.0)
        self._enter_state(GraspState.IDLE)

调参经验（寄存器级 / 参数级）

12.1 舵机PID（如果用智能舵机）
参数   初始值   调参口诀   注意
P   2~5   先调P，从小到大   太大→振荡

I   0   舵机积分易饱和，慎用   除非有稳态误差

D   0.1~0.5   P调好后加D抑制振荡   太大→高频抖动

12.2 PWM死区与分辨率

STM32 TIM 计数器：1MHz (PSC=71)
ARR = 20000 → 周期20ms
CCR分辨率 = 1μs

脉宽范围：500~2500μs
角度分辨率 = 180° / 2000μs = 0.09°/μs

实际精度受限于舵机齿轮间隙（±3°~8°），
所以软件分辨率远超硬件极限，无需追求更高。

12.3 YOLO推理调参
参数   推荐值   调整场景
conf   0.6~0.75   漏检→降低；误检→升高

iou   0.45   多目标重叠→降低

imgsz   640   小目标→增大到1280（但变慢）

max_det   1   你的场景只有1个目标

half   False   RTX 4060不需要FP16

device   0   GPU编号

12.4 轨迹速度调参流程

Step 1: 设 MAX_VEL=10°/s, MAX_ACC=5°/s² → 极慢，观察是否到位
Step 2: 逐步加倍 → 20, 40, 60 → 观察是否过冲/振荡
Step 3: 找到开始振荡的速度 → 取70%作为工作速度
Step 4: 加速度取速度的50%
Step 5: 验证重复定位精度（同一目标10次）

12.5 红外对管调参流程

Step 1: 无物体时读GPIO → 应为HIGH(1)（内部上拉）
Step 2: 放物体遮挡 → 应为LOW(0)
Step 3: 如果无物体也是LOW → 环境光太强 → 加遮光筒
Step 4: 如果有物体也是HIGH → 对管没对准 → 调整位置
Step 5: 在阈值边缘反复测试 → 加软件去抖（5次中3次）
Step 6: 连续运行10分钟 → 检查温漂

void emergency_stop(void) {
    // 所有PWM占空比归零（舵机断电，自由落体）
    TIM1->CCR1 = 0;
    TIM1->CCR2 = 0;
    TIM1->CCR3 = 0;
    TIM1->CCR4 = 0;
    TIM2->CCR1 = 0;
    TIM2->CCR2 = 0;
    
    // 或者：保持当前位置（更安全，防止臂掉落）
    // 不修改CCR，只是停止接收新命令
    
    CDC_Send("ESTOPrn");
}

15.1 AI生成机械臂代码的强制规则

单位与坐标
[ ] 文件头声明：角度单位=度，长度单位=mm，时间单位=ms

[ ] 有超时保护（任何动作>10s未完成→停止）
[ ] 有DRY_RUN模式（只打印不执行）
[ ] 有工作空间可达性检查（is_reachable）

通信
[ ] 串口发送后有超时等待ACK
[ ] 接收有环形缓冲区，不在中断里做解析
[ ] 有重连机制（USB断开后自动恢复）
[ ] CDC接收回调后必须重新使能接收
[ ] 超过64字节必须分包发送

运动
[ ] 轨迹插补在STM32端完成（不依赖PC发送频率）
[ ] 有消隙策略（单方向逼近）
[ ] 下降阶段Z单调递减
[ ] 有软启动（舵机逐个使能）
[ ] 到位判定：连续3周期误差<0.5°

视觉
[ ] YOLO推理前有预热
[ ] BBox中心提取后有置信度过滤
[ ] 像素→mm转换用标定矩阵，不是硬编码比例
[ ] 中文路径用np.fromfile读取
[ ] 标定用getPerspectiveTransform（4点），不用getAffineTransform（3点）

传感器
[ ] 红外读取有去抖（≥3/5次采样）
[ ] 红外状态有"持续触发"判定（非单次）
[ ] 有环境光变化时的重新校准接口

代码质量
[ ] 禁止time.sleep()做长等待（用非阻塞状态机）
[ ] 禁止try:except:pass（必须记录错误码）
[ ] 禁止硬编码魔术数（提取到config.py）
[ ] 多线程共享资源必须加锁
[ ] 所有串口操作在同一个线程（或用队列）

16.1 分阶段联调（硬件到货后）

Phase 1: 最小系统验证（Day 1）
  ├── 1.1 ST-Link烧录固件 → 确认无报错
  ├── 1.2 USB CDC枚举 → 设备管理器出现COM口
  ├── 1.3 pyserial打开 → 发送'H' → 收到'OK'
  └── 1.4 接1个舵机 → 发送'M0 90' → 舵机转到中位

Phase 2: 全舵机验证（Day 1-2）
  ├── 2.1 接6个舵机 → 逐个测试'M0'~'M5'
  ├── 2.2 软启动测试 → 6个依次回中位，观察电源
  ├── 2.3 全范围扫描 → 每个舵机0°~180°，听有无异响
  └── 2.4 急停测试 → 发送'E' → 所有舵机停止

Phase 3: 传感器验证（Day 2）
  ├── 3.1 红外接线 → 发送'I' → 无遮挡返回'IR:0,0'
  ├── 3.2 遮挡测试 → 返回'IR:1,0'或'IR:1,1'
  ├── 3.3 去抖验证 → 快速遮挡/释放，无误触发
  └── 3.4 环境光测试 → 开灯/关灯/阳光直射

Phase 4: 视觉验证（Day 2-3）
  ├── 4.1 摄像头打开 → DroidCam或USB
  ├── 4.2 YOLO推理 → 检测木块，置信度>0.6
  ├── 4.3 四点标定 → 点击4个标定点
  ├── 4.4 精度验证 → 已知位置的物体，误差<5mm
  └── 4.5 光线变化测试 → 开灯/关灯后重新检测

Phase 5: 运动学验证（Day 3）
  ├── 5.1 IK正解验证 → 给定角度→FK→对比目标位置
  ├── 5.2 单点到达 → 臂移到指定XY，用尺量
  ├── 5.3 多点轨迹 → 画正方形/圆形
  ├── 5.4 消隙验证 → 同一点从不同方向到达，对比偏差
  └── 5.5 速度测试 → 逐步加速，找到振荡阈值

Phase 6: 抓取全流程（Day 3-4）
  ├── 6.1 状态机空跑（DRY_RUN=True）
  ├── 6.2 接近阶段 → 臂到目标上方
  ├── 6.3 下降阶段 → 逐层下降，红外触发
  ├── 6.4 夹持阶段 → 夹爪闭合，提起
  ├── 6.5 搬运阶段 → 移到放置位
  ├── 6.6 释放阶段 → 夹爪张开
  └── 6.7 连续10次抓取 → 统计成功率

Phase 7: 鲁棒性测试（Day 4-5）
  ├── 7.1 不同位置放置木块 → 10个随机位置
  ├── 7.2 光线变化 → 开灯/关灯/窗帘
  ├── 7.3 连续运行30分钟 → 检查热漂移
  ├── 7.4 通信干扰 → 拔插USB线，观察恢复
  └── 7.5 异常恢复 → 中途断电/急停后重启

16.2 验收标准
指标   目标   测量方法
抓取成功率   ≥70%（10次中7次）   连续10次抓取

XY定位精度   ±5mm   尺子量

单次抓取时间   <15s   计时

通信丢包率   <1%   发100条统计

连续运行时间   ≥30min无故障   持续运行

红外误触发率   <5%   无物体时100次读取

附录A：完整接线表

STM32F103C8T6 引脚分配：

PA0  → TIM2_CH1 → 舵机5 (J5)
PA1  → TIM2_CH2 → 舵机6 (J6 夹爪)
PA8  → TIM1_CH1 → 舵机1 (J1 底座)
PA9  → TIM1_CH2 → 舵机2 (J2 大臂)
PA10 → TIM1_CH3 → 舵机3 (J3 小臂)
PA11 → USB_DM   → ⚠️ 不可做PWM
PA12 → USB_DP   → ⚠️ 不可做PWM
PA13 → SWDIO    → ST-Link调试
PA14 → SWCLK    → ST-Link调试
PB0  → GPIO_IN  → 红外对管1
PB1  → GPIO_IN  → 红外对管2
PB13 → TIM1_CH4(重映射) → 舵机4 (J4 腕部)

电源：
6V+ → 舵机VCC排（并联）
6V- → 舵机GND → STM32 GND（共地）
USB 5V → STM32板载LDO → 3.3V MCU
