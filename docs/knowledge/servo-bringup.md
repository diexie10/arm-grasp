# 舵机逐轴 Bring-Up 指南

> 基于 2026-08-23 J1（底座）实测经验，为剩余5轴提供标准化流程。
> 每接一个新舵机，按此文档走一遍。

---

## 一、硬件接线（每轴重复）

### 1. 供电

```
6V 8A 电源 → PTC 保险丝 → 滤波模块输入 → 滤波模块输出 → 舵机红线(+6V) / 棕线(GND)
```

- 共地必须：滤波模块 GND ↔ 板子 GND 直连（不借道 CH340）
- 电源严禁接 STM32 3.3V/5V 引脚

### 2. 信号线

```
舵机黄线 → 100Ω 电阻 → 对应 GPIO 引脚
```

引脚映射（铁律，勿改）：

| 舵机 | 关节 | 定时器 | GPIO | M 命令 |
|------|------|--------|------|--------|
| S1 | J1 底座 yaw | TIM1_CH1 | PA8 | M1 |
| S2 | J2 大臂 pitch | TIM1_CH2 | PA9 | M2 |
| S3 | J3 小臂 pitch | TIM1_CH3 | PA10 | M3 |
| S4 | J4 腕俯仰 | TIM2_CH1 | PA0 | M4 |
| S5 | J5 腕旋转 | TIM2_CH2 | PA1 | M5 |
| S6 | J6 夹爪 | TIM2_CH3 | PA2 | M6 |

### 3. 上电前必检

| 检查项 | 方法 | 期望 |
|--------|------|------|
| +6V 对 GND 不短路 | 万用表蜂鸣档 | 不响 |
| 电源极性正确 | DC 电压档量舵机红棕 | ~6V |
| 共地连通 | 板子 GND ↔ 舵机棕线 | ≈0V |
| 信号线导通 | 欧姆档量 GPIO 引脚 ↔ 黄线 | ~100Ω |

## 二、固件配置（已完成，无需每轴改）

### 已修复的 bug（2026-08-23）

1. **HAL_TIM_PWM_MspInit 缺失**（根因）
   - 文件：`Core/Src/stm32f1xx_hal_msp.c`
   - 新增 `HAL_TIM_PWM_MspInit()` 覆盖 `__weak` 空默认
   - 作用：使能 TIM1/TIM2 时钟

2. **SERVO_MAX_ANGLE 校准**
   - 文件：`Core/Inc/main.h`
   - `SERVO_MAX_ANGLE = 180`（仿品 MG996R ~250° 行程）
   - 脉宽映射：`500 + angle × 2000 / 180`

### 烧录方式

Keil 克隆 ST-Link DLL 不兼容，用 pyod：

```powershell
pyocd flash "MDK-ARM\arm-grasp\arm-grasp.axf" -t stm32f103c8 --frequency 100000
```

烧录后必须**断电重启**（清 IWDG），SWD reset 不够。

## 三、逐轴测试流程

### Step 1：接线 + 上电

按上述接线图接好，上电前检查表通过后合闸。

### Step 2：串口验收

```powershell
# 查状态
S → S1=90 S2=90 ... S6=90

# 单轴测试（以 M2 为例）
M2 90  → OK M2 90
M2 45  → OK M2 45
M2 135 → OK M2 135
M2 90  → OK M2 90
```

### Step 3：方向确认

每个舵机的安装方向不同，需要确认：
- 发 Mx 0 → 记录物理旋转方向
- 发 Mx 180 → 记录物理旋转方向
- 哪边是"左"、哪边是"右"，写入标注

### Step 4：行程测量

用 protractor 或手机水平仪：
1. Mx 90 → 记录物理角度（归中位）
2. Mx 0 → 记录物理角度（右极限）
3. Mx 180 → 记录物理角度（左极限）
4. 计算：实际行程 = 左极限 - 右极限
5. 如果实际行程 ≠ 180°（仿品常见），调整 `SERVO_MAX_ANGLE`

### Step 5：连续性测试

跑 5 轮 中→左→中→右 循环，确认：
- 无丢步（每次回到同一位置）
- 无异响（齿轮扫齿声）
- 无抖动（到位稳定）

## 四、每轴标定数据记录模板

```
## 舵机 Sx（Jx 关节名）

- 型号/批次：
- 实测行程：___° （固件 0-180° 对应物理 ___° ~ ___°）
- 方向：Mx 增大 = 物理（左/右/顺时针/逆时针）
- 归中偏移：Mx 90 实际物理 ___°（理想 = 正前方）
- JOINT_OFFSET = ___°
- 备注：
```

### 已校准数据

#### S1 — J1 底座（2026-08-25）

- 实测脉冲响应范围：500~2611µs（逻辑 0~191°）
- 校准基准点：
  - 逻辑 7° = 物理 0°（脉冲 500µs）= 真零位
  - 逻辑 101° = 物理 94°（脉冲 1544µs）= 真中位（横平竖直）
  - 逻辑 191° = 物理 184°（脉冲 2544µs）= 真满位
- servo_trim = **-7**（物理 = 逻辑 - 7）
- joint_min/joint_max = **7 / 191**
- HOME = **101**（物理 94°，脉冲 1544µs）

#### S2 — J2 大臂（2026-08-25）

- 实测脉冲响应范围：0~191°（逻辑 0~191°）
- 校准基准点：
  - 逻辑 3° = 物理 0°（脉冲 500µs）= 真零位
  - 逻辑 93° = 物理 90°（脉冲 1544µs）= 真中位（大臂水平）
  - 逻辑 183° = 物理 180°（脉冲 2544µs）= 真满位
- servo_trim = **-3**（物理 = 逻辑 - 3）
- joint_min/joint_max = **3 / 183**
- HOME = **93**（物理 90°，大臂水平）

## 五、已知陷阱速查

| 陷阱 | 表现 | 解决 |
|------|------|------|
| HAL_TIM_PWM_MspInit 缺失 | TIM 寄存器全零、PA 无输出 | stm32f1xx_hal_msp.c 添加回调 |
| Keil DLL 克隆不兼容 | Flash Download failed | 改用 pyod flash |
| pyod 干扰 IWDG | 寄存器读零、串口偶尔通 | 断电清狗 + 代码禁用 IWDG 调试 |
| SERVO_MAX_ANGLE 错误 | 舵机行程压缩/超限 | 实测行程后调整 main.h |
| 方向反转 | Mx 增大 ≠ 预期方向 | 记录方向，软件补偿 |
| 共地缺失 | 信号浮空、舵机不动 | 板子 GND ↔ 滤波模块 GND 直连 |
| 100Ω 虚接 | 信号不到舵机 | 万用表量通断（应≈100Ω） |
| 舵机供电虚接 | 空载有电、带载塌压 | 拧紧螺丝端子，量带载电压 |
