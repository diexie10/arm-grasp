# 外部调研：机械臂模拟软件选型（硬件到货前预演）

> 调研日期：2026-08-18（@librarian）
> 背景：硬件未到货，想在电脑上模拟机械臂 + 视觉抓取流程（SEARCH→ALIGN→下降→抓取），预演/验证算法。
> 结论：**PyBullet 首选**（免费、纯 Python、URDF 导入、摄像头渲染、内置 IK，任何笔记本可跑）；MuJoCo 次选（接触物理最准）。

## 2. 推荐排序（针对本项目：自制 6DOF + Python YOLO 视觉伺服预演）

1. **PyBullet** — 最匹配"快速预演算法"：pip 秒装、YOLO 检测代码零改动接入（`p.getCameraImage()` → numpy → 模型）
2. **MuJoCo** — 想更贴近真实抓取物理时切它（接触求解精度公认最好），与 PyBullet 可共存于同一工程，URDF 都能导入
3. Webots — 完整 GUI 软件，社区模型多，但对纯代码预演偏重
4. CoppeliaSim Edu — 非在校生不适用
5. Isaac Sim — 仿真天花板但硬件门槛太高，单臂预演大材小用
6. Gazebo — Windows 支持实验性，不划算
7. RoboDK — 工业离线编程定位，免费版限制多

## 3. 用 PyBullet 预演"SEARCH→ALIGN→下降→抓取"的可行性

完全可行：
1. **SEARCH**：`p.getCameraImage()` 渲染 RGB → 直接喂已有 YOLO 模型 → 得到目标像素坐标（检测代码零改动）
2. **ALIGN**：同一循环里——读图 → YOLO 算像素偏差 → `p.calculateInverseKinematics()` 微动 → 重复直到对齐（正好验证像素闭环算法；可随时 `p.stepSimulation()` 步进调试）
3. **下降**：末端直线下移逐点逆解，可加碰撞检测
4. **抓取**：真实接触碰撞（两指夹爪）看物体是否稳定抓起/掉落；或 `p.createConstraint()` 简化绑定——**能直接验证逆解位姿在物理上是否成立**

## 4. sim-to-real 关键提醒

MG996R 是**开环位置控制**（无编码器、有虚位/背隙），真实接触行为/刚度/下垂与仿真差距大。
→ 模拟目的是**预演验证算法逻辑**（视觉伺服收敛、逆解、状态机），**不是精确复现物理**。
→ 仿真通过后，真机只需在接触环节微调。这也是选轻量 PyBullet 而非高保真 Isaac Sim 的原因。

## 5. 落地建议

- 主力：**PyBullet**（最快验证算法流程）
- 进阶：同一工程切 MuJoCo 对比抓取接触物理
- 两者零成本、零硬件门槛，URDF 均可导入
- URDF 建模：可用机械臂3D模型.step 导出（FreeCAD 可转），或按官方 L1/L2/L3/L4 参数手写 URDF（简单连杆+关节即可，无需精确外观）
